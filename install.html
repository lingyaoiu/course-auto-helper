网课助手 一键安装

智慧树 / 学习通 等网课平台的自动刷课工具。选中你的情况，跟着点一下就行。

方式一：下载安装包（推荐，最省事）

点下面的按钮，下载一个小文件，双击运行即可。全程只做：下载 → 解压 → 启动本地服务。

⬇ 下载 一键安装.bat 📖 查看图文教程

下载后如果浏览器提示「不常下载」，选「保留」；运行后如果 Windows 提示「未知发布者」，选「更多信息 → 仍要运行」。

方式二：复制一行命令（1 秒装完）

按 Win + X → 打开「终端」或「Windows PowerShell」→ 粘贴下面这行 → 回车。

irm https://gh-proxy.com/https://raw.githubusercontent.com/lingyaoiu/course-auto-helper/main/install.ps1 | iex

如果提示「禁止运行脚本」，先执行一次：Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

装完检查这 3 步

1
目录 C:\Users\你\CourseHelper 存在，里面有 6 个 .user.js
2
浏览器打开 http://127.0.0.1:8765/health，显示 {"ok":true} 就成功
3
浏览器装好 Tampermonkey（或重开 OCS，脚本会自动装）

用之前先双击 CourseHelper\启动AI服务.cmd，那个黑窗口就是 AI 服务，别关。
